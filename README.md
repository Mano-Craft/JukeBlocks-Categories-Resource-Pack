# 🎙️ JukeBlocks Fan Texture Pack

> **Hinweis:** Dies ist ein **inoffizielles Fan-Projekt** und steht in keiner Verbindung zu EinfachGustaf oder dem JukeBlocks-Podcast.

Dieses Resource Pack bringt den **JukeBlocks-Podcast** nach Minecraft! Ausgewählte Musikschallplatten wurden durch eigene Sounds und passende Texturen ersetzt, sodass du die verschiedenen Podcast-Kategorien direkt über eine Jukebox abspielen kannst.

## Features

* 🎵 Eigene Sounds für die JukeBlocks-Kategorien
* 💿 Angepasste Music Disc-Texturen
* 🎨 Einfaches, zum Podcast passendes Design
* 🧱 Einfach als Resource Pack verwendbar

# 🎙️ JukeBlocks Fan Texture Pack

> **Note:** This is an **unofficial fan project** and is not affiliated with EinfachGustaf or the JukeBlocks podcast.

This Resource Pack brings the **JukeBlocks podcast** into Minecraft! Selected music discs have been replaced with custom sounds and matching textures, allowing you to listen to the different JukeBlocks categories directly through a Jukebox.

## Features

* 🎵 Custom sounds for the JukeBlocks categories
* 💿 Custom Music Disc textures
* 🎨 A simple design inspired by the podcast
* 🧱 Easy to use as a Resource Pack
